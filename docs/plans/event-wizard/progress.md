## 实现

所有事项从类型与名称开始，底部前后切换，顶部不显示步骤编号。字段、关联资料及搜索结果保持草稿；保存失败与关闭保护保留原体验。新事项取消确认复选框，默认计划中，不凭空标记已确认。

统一时间组件支持分钟、单个时刻、时间段、每端时区与时间待定，保留夏令时重复/缺失时刻校验。保存 timeRange 标志以正确恢复开关状态；各类事项详情展示结束时间。Ant Design 浮层位于弹窗焦点范围内、滚动内容外，不撑高弹窗，并关闭动画以兼容系统减少动态效果。

地点通过已登录的 Worker 接口代理 Geoapify，保存结果名称、完整地址及 WGS84 坐标。旧文字地址兼容保留。导航采用 Apple Maps 坐标路线链接，旧地址使用文字搜索。上传位于资料网格，上传后同时保存到旅行资料并自动关联。
