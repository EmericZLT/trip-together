# 03 看板与验收

创建私有的 Umami 产品使用看板：D1 总量快照（明确更新时间和口径）、事件趋势、注册/创建/事项与多人协作目标、功能使用分布。自定义 Board 使用已核实的实例 API；不创建公开分享链接。

## Todo / 门禁

- CLI 读取私密配置，按名称复用既有资源，创建后读取核验。
- 定期更新存量统计快照，不把快照值求和当用户数。
- API 版本或权限不足时保留可运行的配置工具和准确的未完成记录，不声称已创建。
- 测试通过，文档、密钥样例、开启/关闭步骤齐全；交付看板链接和验证证据。

## 阶段目标

建立管理员可用的真实 Umami 产品看板。

## 测试方案

只读核验实例与网站，创建后读回，检查事件接收和总量快照。

## 完成门禁

真实实例 API 调用成功，读回配置与接收结果完整。

## 交付物

可重用配置脚本、运行手册、真实看板链接。
