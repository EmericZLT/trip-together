# 02 可靠发送

使用 D1 触发器与业务写入同事务记录事件，再由 Worker 定时批量发送 OpenPanel，外部失败不能中断用户保存。用户 ID 使用独立 HMAC 密钥转为匿名标识。发往固定实例地址，忽略客户端提供的 URL 和个人数据。

## Todo / 门禁

- 持久队列、租约、退避重试与诊断计数，停用时不发送。
- local 环境永不外发；不以 Cloudflare 出口地理位置解释用户来源。
- 浏览行为只允许预定义页面与行为名称，尊重浏览器 DNT 和本地停用。
- 验证鉴权、错误隔离、并发发送、边界校验；交付发送模块和测试。

## 阶段目标

可靠采集并发送最少必要的匿名事件。

## 测试方案

模拟拒绝、超时、并发租约、重复 ID、禁用与私密字段拒绝。

## 完成门禁

本地不外发，失败保留队列，业务流程回归通过。

## 交付物

worker/analytics、浏览端采集模块与测试。

业务节点全量：由后台批次查询并保存到事件 data.totals，首次发送前持久保存；失败重试保留快照。采样与发送不进入认证请求，total_* 使用与 summary 相同的 SQL 口径，totals_sampled_at 与业务时间分别记录。
